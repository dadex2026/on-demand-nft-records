Card verifier

Checks a card against the published records: the day's commitment and its memo, the drand round, the secret, the config, the rolls, the number and the image. Runs entirely in this page; it fetches only the records and the RPC you give it.

Not verified against the official on-demand-nft records.

    Independent of the project's own code. Built with @noble/curves 2.4.0 and @noble/hashes 2.4.0, embedded; no other code is loaded.
